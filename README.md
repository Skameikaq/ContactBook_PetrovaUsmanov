# ContactBook_PetrovaUsmanov Создание приложения Контактная книга. Работу выполнили Петрова София и Усманов Кирилл. ИР 23-4
## Описание проекта
Приложение "Контактная книга" представляет собой удобный инструмент для быстрого взаимодействия с контактной информацией. Это простое Android-приложение, которое позволяет одним нажатием кнопки позвонить, отправить email, найти офис на карте или поделиться контактом.

## Функциональность
Приложение реализует следующие возможности:

*   **Позвонить:** Открывает набор номера +7 (495) 123-45-67. Пользователю остаётся только нажать кнопку вызова.
*   **Написать email:** Открывает почтовое приложение с автоматически заполненными полями: адрес `contact@example.com` и тема «Обращение».
*   **Показать офис на карте:** Открывает карту с меткой «Наш офис» по координатам 60.0237, 30.2289.
*   **Поделиться контактом:** Открывает диалог выбора приложения для отправки текста с контактной информацией.
*   **Обработка ошибок:** Если на устройстве нет подходящего приложения (например, почтового или карт), пользователь увидит понятное всплывающее сообщение (Toast).
